# 🔄 Weekly Reviews

Do a review at the **end of each week** (after Day 7, 14, 21, 28). ~20–30 min. It converts a pile
of ticked boxes into a **decision about next week**.

For every review, compute these from the Notion databases:

| Metric | Where |
|--------|-------|
| Planned hours | 14 (7 days × 2 h) |
| Actual hours | `sum(Actual Hours)` on Daily Study Tracker, that week's rows |
| Completion % | avg `Daily Completion %` for the week |
| Topics completed | Master Topic Tracker: `Status = 🟢 Completed` for that week |
| Topics pending | Master Topic Tracker: `Status ≠ 🟢` for that week |
| Topics needing revision | `Status = 🔵 Needs Revision` |
| Challenges completed | Weekly Challenge Tracker: `Status = Completed` |
| Average confidence | avg `Confidence` across that week's topic rows |
| Weakest domain | lowest avg `Completion %` / `Confidence` |
| Strongest domain | highest avg `Completion %` / `Confidence` |

Standard checklist (same each week):

- [ ] Completed all planned topics for the week
- [ ] Completed all planned hands-on workflows
- [ ] Completed the week's Weekly Challenge(s)
- [ ] Completed the week's Practice Questions
- [ ] Reviewed every mistake logged this week
- [ ] Updated Confidence (1–5) on every topic touched
- [ ] Identified weak topics (Confidence ≤ 2)
- [ ] Scheduled revision for each weak topic into next week's recall slots
- [ ] Updated total study hours
- [ ] Wrote next week's focus adjustment
